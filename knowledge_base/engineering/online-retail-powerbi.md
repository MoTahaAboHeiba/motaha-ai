# Online Retail Power BI Report — Mohamed Taha Abo Heiba

Mohamed Taha Abo Heiba built the Online Retail Power BI Report to demonstrate data cleaning, feature creation, DAX measures, and business analysis over an online retail transaction dataset. The portfolio presents the project as a Power BI report with revenue, average order value, trend, customer, country, and geographic analysis.

## Online Retail Power BI Report — Portfolio Facts

The portfolio's report diagram states that the raw data contains 541K transaction rows. The cleaning flow removes 135K rows with null IDs, 10.6K rows with invalid quantities, and 9.3K cancellations, leaving 406K clean rows. The report adds 8 new features and contains 5 DAX measures.

The portfolio states that the report presents 9.73M revenue, 4,372 customers, 38 countries, and 3 report pages covering 13 months. These figures are portfolio-presented report facts; the workspace does not contain a PBIX file or a `Docs/DAX_FORMULAS.md` file for independent measure verification.

## Online Retail Power BI Report — Analysis Areas

The portfolio identifies revenue, average order value, trends, and geographic analysis as the report's analysis areas. The available portfolio HTML does not list the names or formulas of the five DAX measures, so this document does not invent them.
