Approach & Background

I approach data infrastructure as a systems problem, not a collection of scripts. A pipeline that runs once is not the same as one that runs correctly every day, and most of the real engineering work lives in that gap: catching failures before they reach a report, every transformation, and keeping each layer of the system separated so one change doesn't break three others downstream.

Certified in Huawei HCIA-Big Data (best trainee across 30+ participants, first attempt) and AWS Cloud Practitioner. Computer Science degree, GPA 3.4/4.0.

Increasingly focused on Data Engineering for AI workflows: building and benchmarking vector store pipelines, embedding systems, and retrieval APIs that run in production,not just in a notebook. The same reliability principles apply here, validated ingestion, measurable latency, and clean separation between indexing and serving. Retrieval quality is measured with an offline evaluation harness, not assumed to be good.
